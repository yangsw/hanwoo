# hanwoo — 한우 농장 관리

GitHub Pages 정적 사이트로 돌리는 한우 사육·번식·질병 관리 노트입니다.

- 저장소: https://github.com/yangsw/hanwoo
- 페이지: https://yangsw.github.io/hanwoo/

## 구조

- `index.html` — 메인
- `dashboard/` — 농장 현황
- `cattle/` — 개체·혈통
- `reproduction/` — 발정·인공수정·임신·분만
- `health/` — 질병·접종·발급
- `feeding/` — 사료·급여·사료비
- `growth/` — 체중·초음파·출하
- `records/` — 이력
- `data/` — JSON 샘플
- `resources/` — 한·일 자료·수의·영상 (기존 스크랩 이전)
- `iot/`, `ai/` — 신호·분석 플레이스홀더

샘플 개체는 `data/cattle.json` 입니다. 실제 농장 데이터로 교체하면 됩니다.
